# Report Screenshots

Capture the finished report in Power BI Desktop and save the images in this directory using the filenames below.

```text
screenshots/
├── 01-sales-overview.png
├── 02-regional-analysis.png
├── 03-product-analysis.png
├── 04-profitability-analysis.png
└── 05-product-ranking.png
```

## Capture guidelines

- Use the same report window size for all five pages.
- Hide unnecessary panes if they cover the report canvas.
- Keep the page title, KPI cards, charts, and slicers visible.
- Avoid screenshots where labels are clipped or text is too small.
- Make sure the images do not expose personal or confidential information.

After adding the images, place them in the README with Markdown, for example:

```markdown
## Sales Overview

![Sales Overview](screenshots/01-sales-overview.png)
```

Add a similar section for each page once the corresponding image file exists.
