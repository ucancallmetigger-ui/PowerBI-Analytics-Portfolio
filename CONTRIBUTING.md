# Project Notes

This repository documents a Power BI portfolio report built with the Sample Superstore dataset.

When updating the project:
- Keep the DAX documentation aligned with the PBIX.
- Recheck date relationships and sort settings after editing the calendar table.
- Test slicers and cross-filtering after changing visuals.
- Replace screenshots if the report layout changes.
- Do not commit confidential data, credentials, or files you are not permitted to redistribute.
